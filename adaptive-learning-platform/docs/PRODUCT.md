# Product

Arc optimizes for the minimum instruction required to produce durable, transferable, independent capability. Its unit of progress is evidence, not content completion.

The primary path is goal → depth selection → mission review → diagnostic → adaptive session → evidence update → remediation or acceleration → spaced review → integrated project → objective evaluation → viva → capability report.

V1 is intentionally single-learner oriented and calm: one cognitive task dominates each lesson screen. The seeded LLM fine-tuning mission demonstrates the complete product language and state transitions while remaining reproducible offline.

Non-goals include social features, certificates, payments, streak economies, marketplaces, avatars, classrooms, and autonomous crawling.
